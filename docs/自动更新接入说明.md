# 自动更新接入说明

## 当前状态

- 应用内已接入 `update-electron-app`
- Windows Squirrel 安装版在启动时自动检查更新。Windows 便携 ZIP 通过托盘检查版本并打开下载页。
- 检测到新版本后会后台下载，并在下载完成后提示重启安装
- `macOS / Linux` 仍然保留为手动更新
- 托盘菜单里的 `Check for updates` 现在会在受支持平台触发应用内检查

## 发布链路调整

- Windows 构建已改为同时产出 `Squirrel` 更新所需文件
- Release 工作流会上传：
  - macOS `.zip`
  - Windows `Setup.exe`
  - Windows `.nupkg`
  - Windows `RELEASES`
  - Linux `.deb`

## 版本与验收

发布标签必须高于历史正式版。仓库曾发布 v1.1.11，当前源码的候选版本为 v1.1.12。CI 会检查 GitHub 上所有已发布的正式版本，并保留 v1.1.11 作为历史下限。

1. PR 的 Windows 作业会构建 x64 安装包和便携 ZIP，并核对 `RELEASES` 中完整更新包的文件名、大小与 SHA-1。
2. 在 Windows 上用两个依次递增的 Squirrel 安装版本验证后台下载、重启安装和会话保留。Electron 公共更新服务依赖已发布的正式 Release。
3. 已使用旧版 ZIP 的用户可以手动下载安装版，或继续使用便携 ZIP 并手动更新。
