# 自动更新接入说明

## 当前状态

- 应用内已接入 `update-electron-app`
- `Windows` 的正式打包版本会在启动时自动检查更新
- 检测到新版本后会后台下载，并在下载完成后提示重启安装
- `macOS / Linux` 仍然保留为手动更新
- 托盘菜单里的 `Check for updates` 现在会在受支持平台触发应用内检查

## 发布链路调整

- Windows 构建已改为同时产出 `Squirrel` 更新所需文件
- Release 工作流会上传：
  - macOS `.zip`
  - Windows `Setup.exe`
  - Windows `.nupkg`
  - Windows `RELEASES`
  - Linux `.deb`

## 正式发布前仍需完成

- 当前方案不再包含 macOS 自动更新，因此不要求 Apple 签名和 notarization
- 如果未来要恢复 macOS 自动更新，再补：
  - macOS 代码签名
  - macOS notarization
  - GitHub Actions 中对应证书和密钥

## 建议验收顺序

1. 先发一个测试版 tag，确认 Windows Release 里已经包含 `Setup.exe`、`.nupkg` 和 `RELEASES`
2. 在一台已安装旧版 Windows 机器上验证自动下载和重启安装
3. 如未来有 Apple 开发者证书，再补 macOS 自动更新链路
